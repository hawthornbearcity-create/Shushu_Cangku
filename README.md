# 壁纸与主题中心 0.2.5 · Windows 分享版

为 Windows Codex 桌面客户端设置图片壁纸与主题色，包含源码和本地安装入口。

## 安装与首次启用

1. 将整个 ZIP 解压到一个固定、可写的文件夹。不要直接在压缩包内运行脚本。
2. 电脑需已安装 Codex 和 Node.js 22.15 或更新版本。工具优先使用 Codex 缓存中的 Node，也支持 PATH 中的 node.exe；不需要 npm install。
3. 双击“安装到Codex.cmd”，注册插件，并自动生成使用本包图片图标的桌面启动快捷方式。它会保留已有的其他插件条目。
4. 保存工作，从托盘完全退出 Codex，再双击桌面上带图片图标的“启动壁纸版Codex”。也可继续运行“启动壁纸版Codex.cmd”。
5. 连接后点击 Codex 右下角“壁纸主题”，选择图片、配色和透明度。日常调整无需反复退出。

请保留解压后的完整文件夹。安装后的另一份入口位于：
`%USERPROFILE%\.codex\plugins\codex-wallpaper-studio\启动壁纸版Codex.cmd`

当前版本自动适配的客户端位置为：
`%LOCALAPPDATA%\Programs\Codex\ChatGPT.exe`
其他安装位置及客户端版本尚未验证；找不到路径、签名不匹配或页面不支持时会停止并提示，不应修改客户端安装包或系统权限来强行连接。

## 功能

- PNG、JPEG、WebP 壁纸导入；单张原图不超过 12 MB，最多 30 张。
- 晴空蓝、深海夜、山岚绿、暖沙色，以及自定义强调色、底色和文字色。
- 壁纸强度、模糊、亮度、图片位置与填充方式。
- 侧栏与面板不透明度：25%–100%。
- 聊天区域不透明度：0%–100%，默认 20%；0% 完全透明，100% 完全不透明。
- 新聊天、已有聊天和缓存会话切换时，重新识别可见聊天主区域。
- 恢复默认外观，保留个人壁纸库。

本版尚不支持右侧文件／浏览器／预览标签面板的不透明度调整。该区域和聊天主区域不同，不能用聊天透明度选项代替。

## 自定义启动图标

本包的 `assets/launcher.ico` 使用打包者指定的图片，包含 16、24、32、48、64、128、256 像素图标。

Windows 的单个 .cmd 文件不能直接设置独立图标，因此通过启动快捷方式显示图片图标，原始 .cmd 脚本继续保留。

- 安装时会在桌面生成“启动壁纸版Codex”，目标指向已安装的插件目录。
- 插件目录内也会生成“启动壁纸版Codex（图片图标）.lnk”。
- 不想重新安装时，可在解压目录运行“创建图标快捷方式.cmd”，为该目录创建图片图标入口；此时需保留解压目录。
- 快捷方式由接收者电脑现场生成，ZIP 不携带打包者电脑的绝对路径快捷方式。

## 已有安装的更新

如果当前已通过壁纸入口启动 Codex，可运行“更新壁纸工具.cmd”。它会核验客户端，仅重启本插件自己的主题服务，再更新窗口内控件；不退出 Codex。

如果当前是普通 Codex 启动方式，请按首次启用的第 4 步操作。

## 常用入口

- 安装到Codex.cmd：注册当前用户的本地插件。
- 启动壁纸版Codex.cmd：首次启用壁纸时使用的客户端启动入口。
- 打开主题中心.cmd：打开独立设置页；页面能打开不代表客户端已经连接。
- 更新壁纸工具.cmd：给已连接的客户端加载当前版控件和渲染代码。
- 诊断当前聊天.cmd：保存界面布局诊断，不采集聊天正文、文件正文或截图。

诊断报告可能包含界面结构和程序状态，排障后请按需分享；分享软件时应重新使用本 ZIP，不要把自己运行后的数据目录整体发给别人。

## 数据与恢复

个人壁纸、配色和服务运行数据保存在：
`%USERPROFILE%\Documents\Codex\壁纸主题中心数据`

分享包包含内置示例壁纸及打包者指定的启动图标，不包含原使用者额外导入的壁纸、配置、诊断报告、日志或会话凭据。软件运行时会为每位使用者建立自己的数据目录。

在主题面板点击“恢复默认外观”可暂停壁纸并还原本插件样式，图片库保留。完全退出当前 Codex 后，从原来的普通快捷方式启动，可以结束本次壁纸调试模式。

主题服务仅监听本机 127.0.0.1:19336，客户端调试端口为 19335；连接前会校验 OpenAI 数字签名及端口归属。不要分享运行时主题中心地址中的临时凭据。

## 验证范围

本版聊天透明度修复已由原使用者确认生效。源码测试覆盖配置保存、图片校验、本机接口、安装合并、连接核验和更新检查；浏览器回归覆盖隐藏缓存页面、可见历史聊天、会话切换、缩放、连续更新及还原。
